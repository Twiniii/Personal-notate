# Personal-notate

Консольний застосунок для ведення персональних нотаток на Java.

Лабораторна робота №5 — Рефакторинг програмного коду із застосуванням патернів проєктування.

Програма дозволяє створювати нотатки, переглядати їх, відкривати за номером, шукати за пріоритетом або повним збігом і сортувати. Усі дії виконуються через меню протягом одного сеансу, без перезапуску програми.

Ця версія продовжує ЛР №4. Додано третій формат відображення, повідомлення про додавання нотаток та статистику.

## Вимоги та запуск

Для роботи потрібен установлений JDK 25. Додаткові бібліотеки встановлювати не потрібно.

Перевірити наявність Java та компілятора можна командами:

```powershell
java --version
javac --version
```

Відкрийте CMD або PowerShell у папці проєкту, де розташовані `run.cmd`, `build.cmd` та папка `src`.

Для запуску виконайте:

```powershell
.\run.cmd
```

Скрипт налаштовує UTF-8 для відображення українських символів, компілює програму та запускає її. Якщо під час компіляції виникне помилка, запуск не відбудеться, а повідомлення залишиться в терміналі.

Після успішного запуску з’явиться головне меню.

## Головне меню

Щоб виконати дію, введіть її номер і натисніть Enter.

| Команда | Призначення |
| --- | --- |
| 1 | Додати одну або кілька нотаток |
| 2 | Переглянути всі нотатки в поточному форматі |
| 3 | Знайти нотатки за пріоритетом і порахувати їх |
| 4 | Відсортувати нотатки за пріоритетом |
| 5 | Знайти нотатку за повним збігом усіх полів |
| 6 | Відкрити нотатку за її номером |
| 7 | Змінити формат відображення |
| 8 | Порівняти формати однієї нотатки |
| 9 | Переглянути статистику |
| 0 | Завершити роботу |

Після виконання дії програма повертається до головного меню.

У вікнах вибору нотатки або формату значення `0` повертає до меню, якщо це зазначено в запрошенні.

## Додавання нотаток

Оберіть пункт **1** та вкажіть кількість нотаток, які потрібно додати. Програма покаже допустимий діапазон відповідно до кількості вільних місць.

Для кожної нотатки послідовно введіть:

| Поле | Опис та правила |
| --- | --- |
| Назва | Коротка назва нотатки. Не може бути порожньою або складатися лише з пробілів |
| Текст | Основний вміст нотатки. Може бути порожнім |
| Категорія | Довільна категорія, наприклад «Особисте», «Навчання» або «Робота». Може бути порожньою |
| Пріоритет | Ціле число від 1 до 10. Значення 1 означає найвищий пріоритет, 10 — найнижчий |

Кожне поле підтверджується натисканням Enter.

Текст нотатки вводиться одним рядком. Якщо довгий текст автоматично переноситься на екрані, це лише його відображення. Натискання Enter завершує введення тексту.

Після успішного додавання з’являється повідомлення з позначкою `[Журнал]`, а статистика оновлюється автоматично.

Якщо введено літери замість числа, програма попросить повторити введення. Якщо назва порожня або пріоритет виходить за межі 1–10, під час створення буде запропоновано повторно ввести нотатку.

## Перегляд та відкриття

Пункт **2** показує всі створені нотатки у вибраному форматі.

Пункт **6** спочатку показує лише номери та назви нотаток. Щоб відкрити потрібну, введіть її номер.

Якщо нотаток ще немає, програма повідомить про це. Якщо введено неіснуючий номер, з’явиться повідомлення про помилку й програма повернеться до меню.

Номери відповідають поточним позиціям нотаток у списку. Після сортування вони можуть змінитися.

## Пошук і сортування

### Пошук за пріоритетом

Оберіть пункт **3** та введіть пріоритет від 1 до 10.

Програма покаже всі відповідні нотатки та їх кількість. Якщо збігів немає, з’явиться повідомлення, а кількість знайдених дорівнюватиме нулю.

### Пошук за повним збігом

Оберіть пункт **5** та введіть назву, текст, категорію і пріоритет шуканої нотатки.

Для успішного пошуку повинні збігатися всі чотири поля. У текстових полях враховуються регістр літер і пробіли.

Якщо є кілька однакових нотаток, програма покаже першу знайдену. Введення даних для пошуку не створює нової нотатки.

### Сортування

Оберіть пункт **4**.

Програма покаже нотатки до та після сортування. Спочатку розташовуються нотатки з найвищим пріоритетом: 1, потім 2 і далі до 10.

## Формати відображення

У пункті **7** можна обрати один із трьох форматів:

- **1 — Повний.** Показує назву, текст, категорію та пріоритет окремими рядками.
- **2 — Стислий.** Показує назву, категорію та пріоритет одним рядком. Текст приховано.
- **3 — Застарілий.** Показує всі дані в іншому оформленні з позначкою `[LEGACY]`.

Вибраний формат використовується для наступних переглядів у поточному сеансі.

Зміна формату не змінює дані нотатки. Щоб знову побачити текст після стислого перегляду, достатньо повернути повний формат.

Пункт **8** дозволяє вибрати одну нотатку й побачити її в усіх трьох форматах. Поточний формат перегляду від цього не змінюється.

## Статистика

Оберіть пункт **9**, щоб переглянути:

- загальну кількість успішно доданих нотаток за поточний сеанс;
- кількість нотаток для кожного пріоритету від 1 до 10.

Статистика оновлюється після додавання нотатки. Перегляд, пошук, сортування та зміна формату не збільшують лічильники. Невдала спроба створення також не враховується.

## Приклад користування

1. Запустіть програму, оберіть пункт **1** та введіть кількість **2**.
2. Створіть нотатки з такими даними:

| Назва | Текст | Категорія | Пріоритет |
| --- | --- | --- | --- |
| Покупки | Купити хліб і молоко | Особисте | 5 |
| Java | Повторити інтерфейси | Навчання | 1 |

3. Оберіть пункт **6**, а потім номер **1**. Відкриється нотатка «Покупки».
4. Оберіть пункт **4**. Після сортування першою стане нотатка «Java».
5. Оберіть пункт **7**, потім формат **2**. Через пункт **2** перегляньте нотатки у стислому вигляді.
6. Оберіть пункт **8** та номер потрібної нотатки, щоб порівняти всі формати.
7. Оберіть пункт **9**. Загальна кількість має бути 2, а для пріоритетів 1 та 5 — по одній нотатці.
8. Для завершення роботи введіть **0** у головному меню.

## Зберігання даних

Програма зберігає до 100 нотаток у пам’яті протягом одного сеансу. Якщо всі місця зайняті, додавання нових нотаток буде недоступним.

Запис у файл у цій версії не виконується.

Після закриття програми всі нотатки та статистика втрачаються. Наступний запуск починається з порожнього списку.
