# Personal-notate

Застосунок для ведення персональних нотаток на Java



Лабораторна робота №1 — Реалізація консольного застосунку



Лабораторна робота №1 — Реалізація консольного застосунку



Програма дозволяє створювати нотатку та переглянути її через меню.

Меню працює до вибору користувачем команди виходу.



Після запуску оберіть пункт меню, ввівши його номер і натиснувши Enter:



\- 1. Створити нотатку — послідовно введіть назву, текст, категорію та пріоритет.

\- 2. Переглянути останню нотатку — перегляньте введені дані. Якщо нотатку ще не створено, програма повідомить про це.

\- 0. Вийти — завершіть роботу програми.



Після створення або перегляду нотатки меню з’являється знову.



Поточна версія зберігає одну нотатку в пам’яті.

Нова нотатка замінює попередню, а після закриття програми дані втрачаються.





Нотатка



Кожна нотатка містить:



\- назву — String

\- текст — String

\- категорію — String

\- пріоритет — int



Потрібен установлений JDK 25.



Відкрийте командний рядок у папці проєкту та скомпілюйте програму:

```cmd

javac -encoding UTF-8 Main.java

```



Після успішної компіляції запустіть програму:



```cmd

java Main

```



Якщо українські символи в Windows CMD відображаються неправильно,

перед запуском виконайте `chcp 65001`.
