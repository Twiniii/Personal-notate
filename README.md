# Personal-notate

Застосунок для ведення персональних нотаток на Java


Лабораторна робота №1 — Реалізація консольного застосунку



Програма дозволяє створювати нотатку та переглянути її через меню.

Меню працює до вибору користувачем команди виходу.



Після запуску оберіть пункт меню, ввівши його номер і натиснувши Enter:



\- 1. Створити нотатку — послідовно введіть назву, текст, категорію та пріоритет.

\- 2. Переглянути останню нотатку — перегляньте введені дані. Якщо нотатку ще не створено, програма повідомить про це.

\- 0. Вийти — завершіть роботу програми.



Після створення або перегляду нотатки меню з’являється знову.



Поточна версія зберігає одну нотатку в пам’яті.

Нова нотатка замінює попередню, а після закриття програми дані втрачаються.





Нотатка



Кожна нотатка містить:



\- назву — String

\- текст — String

\- категорію — String

\- пріоритет — int



Потрібен установлений JDK 25.



Відкрийте командний рядок у папці проєкту та скомпілюйте програму:

```cmd

javac -encoding UTF-8 Main.java

```



Після успішної компіляції запустіть програму:



```cmd

java Main

```



Якщо українські символи в Windows CMD відображаються неправильно,

перед запуском виконайте `chcp 65001`.


Лабораторна робота №2 — Опрацювання масивів із застосуванням циклів

У другій лабораторній роботі програма була доповнена роботою з масивом нотаток.

Тепер можна створювати декілька нотаток, які зберігаються в масиві об’єктів Note.

Після запуску оберіть пункт меню, ввівши його номер і натиснувши Enter:



Створити нотатку — введіть назву, текст, категорію та пріоритет.



Переглянути нотатки — перегляньте всі створені нотатки.



Показати нотатки за пріоритетом — введіть потрібний пріоритет та перегляньте нотатки, які йому відповідають.



Вийти — завершіть роботу програми.

Для роботи з нотатками використовується масив об’єктів Note.

У програмі використовуються цикли while, for та for-each.

Також реалізовано сортування нотаток за пріоритетом методом Bubble Sort.

Реалізовано лінійний пошук нотатки за повним збігом об’єкта.

Для порівняння нотаток у класі Note перевизначено метод equals().

Після закриття програми дані, збережені в масиві, втрачаються.

Потрібен установлений JDK 25.

Відкрийте командний рядок у папці проєкту та скомпілюйте програму:

javac -encoding UTF-8 Main.java Note.java

Після успішної компіляції запустіть програму:

java Main

Якщо українські символи в Windows CMD відображаються неправильно,

перед запуском виконайте chcp 65001.
