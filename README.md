# Personal-notate

Консольний застосунок для ведення персональних нотаток.

Лабораторна робота №4 — Реалізація програмних інтерфейсів мовою Java.

## Запуск

Потрібен установлений JDK 25.

Відкрийте термінал у папці проєкту, де розташований файл `run.cmd`, та виконайте:

```powershell
.\run.cmd
```

Команда автоматично скомпілює та запустить програму.

## Користування

Введіть номер пункту меню та натисніть Enter:

- **1 — Додати нотатки.** Вкажіть кількість, потім введіть назву, текст, категорію та пріоритет кожної нотатки.
- **2 — Переглянути нотатки.** Показує всі нотатки в обраному форматі.
- **3 — Знайти за пріоритетом.** Показує відповідні нотатки та їх кількість.
- **4 — Відсортувати за пріоритетом.** Розташовує нотатки від найвищого пріоритету до найнижчого.
- **5 — Знайти за повним збігом.** Потрібно ввести всі чотири поля шуканої нотатки.
- **6 — Відкрити за номером.** Показує список назв і дозволяє відкрити вибрану нотатку.
- **7 — Змінити формат.** Оберіть повний або стислий вигляд.
- **8 — Порівняти формати.** Показує одну нотатку в обох форматах.
- **0 — Вийти.** Завершує роботу програми.

Повний формат показує всі поля. Стислий — назву, категорію та пріоритет одним рядком.

Назва не може бути порожньою. Пріоритет — ціле число від 1 до 10, де 1 означає найвищий пріоритет.

## Зберігання

Програма зберігає до 100 нотаток у пам’яті протягом одного сеансу.

Після закриття програми нотатки втрачаються.
